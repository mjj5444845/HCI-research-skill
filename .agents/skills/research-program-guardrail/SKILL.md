# Research Program Guardrail — AMSC

## Trigger

Apply whenever:
- the user is discussing their own long-term research direction;
- ranking papers for their mainline;
- deciding what to study next;
- running Research Radar;
- updating literature/gaps/exam knowledge;
- comparing possible projects against the PhD trajectory.

Do not force this guardrail onto unrelated one-off research tasks unless the user asks.

## Research identity

> I study how humans and embodied AI agents develop adaptive, socially meaningful multimodal communication through situated interaction.

## Primary relevance question

Does this work help explain how humans and embodied AI:
- establish,
- understand,
- evolve,
- ground,
- conventionalize,
- personalize,
- adapt

shared communication?

Superficial overlap with robot / LLM / emoji / VR / emotion is insufficient.

## Priority chain

Meaning -> Grounding -> Convention -> Adaptation -> Embodied Communication

## Mainline priority

Highest-priority theory:
- Common Ground
- Grounding
- Convention Formation

Mainline development:
1. Informal visual expression
2. Social meaning / pragmatics
3. Grounding / common ground
4. Convention formation
5. Personalization / co-adaptation
6. Situated adaptive communication

## Relevance classification

- MUST_READ
- HIGH
- MEDIUM
- BACKGROUND
- REJECT

### Reject when
The connection is keyword-level only or does not update:
- theory,
- mechanism,
- empirical understanding,
- method,
- gap,
- research trajectory.

## Project guardrail

A project like:

> new effect -> questionnaire -> warmth increases

is normally low priority unless it reveals:
- mechanism;
- boundary;
- social meaning formation;
- grounding;
- convention;
- adaptation;
- interaction-history effect;
- situated communication principle.

## Cross-cultural guardrail

Avoid `Chinese vs American preference` as the default unit of contribution.

Prefer richer models involving:
- communicative priors
- socialization
- language
- diaspora/community
- interaction history
- partner-specific convention
- cultural and relational context

## Decision output

For an idea/paper, report:
- Mainline fit: 0–10
- Which stage(s) it advances
- Which gap(s) it updates
- Whether it changes exam knowledge
- Whether it should change the next-project priority
- Whether it is core, adjacent, or distracting

Do not reject valuable adjacent work merely because it is outside the mainline; label it accurately.
